## Important distinction

The seven checks in TEST_RESULTS.md were run against the local interactive browser prototype. They are not evidence that the Flutter Android app has been compiled, installed, or tested on a physical phone. The Flutter app's own setup and test instructions are in the root README and mobile project folder.

## Local prototype

The original static prototype is a proof of concept for demonstrating quick bills, itemised bills, receipt preview, history search, expenses, and CSV export. It stores demo records in the current browser's local storage. It is not a cloud-synchronised production service.
