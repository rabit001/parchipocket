PARCHIPOCKET ANDROID APP - START HERE

1. Install Flutter and Android Studio on Windows.
2. Open PowerShell in this folder (the folder containing pubspec.yaml).
3. Run: flutter doctor
4. Run: flutter pub get
5. Start an Android emulator or connect a phone with USB debugging.
6. Run: flutter devices
7. Run: flutter run

TESTS
- flutter test --reporter compact
- flutter analyze

AUTHENTICATION
- Phone login uses Firebase Authentication.
- Real SMS OTP requires Phone provider configuration in Firebase.
- Use configured Firebase test numbers during development.
- Google sign-in is demo-only.
- "Skip sign-in" opens local demo data; it is not a cloud account.

PROJECT NOTES
- Current focus: Home & Family daily spending.
- Shop Owner and Street Vendor screens are retained but paused in current navigation.
- PDF export, production printer support, push notifications, and robust offline sync are not production-complete.
- Do not use demo data as a real financial ledger.

Read README.md in this folder and ../../docs/SETUP_GUIDE.md for full setup details.
